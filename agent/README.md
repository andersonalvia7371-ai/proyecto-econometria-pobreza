# Registro de Uso de Inteligencia Artificial (Agentes / LLMs)

Este proyecto contó con el apoyo de herramientas de Inteligencia Artificial como asistente de desarrollo y análisis.

## Herramientas Utilizadas
- **Gemini / ChatGPT / Claude**

## Tareas en las que se utilizó asistencia de IA
1. **Diseño e Interfaz Web (`index.html`):** Generación y estructuración de la maqueta HTML/CSS para la visualización del análisis de pobreza.
2. **Depuración de Errores (Debugging):** Resolución de problemas de entorno de comandos, rutas de archivos y nombres sensibles a mayúsculas/minúsculas.
3. **Flujo de Despliegue:** Orientación en la configuración y despliegue del proyecto en GitHub y Vercel.
